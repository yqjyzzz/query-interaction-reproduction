# 开发说明

## 目录分工

- `artifact/` 是冻结证据层，原则上只读；
- `scripts/` 是使用者入口，负责提供相对路径和统一命令；
- `tests/` 检查仓库契约和复现结果；
- `docs/` 解释研究设计、结果和维护规则；
- `src/` 目前只保存包元数据，不复制一份可能与冻结程序分叉的统计实现。

## 代码约定

运行入口、清单校验器和测试使用 Python 3.12 类型标注，路径显式传递，不下载外部资源。统计核心保留原始脚本，避免因代码重构改变数值行为。

## 修改前后检查

```powershell
python scripts/check_repository.py
```

如果改动分析就绪数据、预期结果、自助法随机种子、估计目标或主张边界，需要新的科学溯源决定。单纯的文档、测试和运行入口改动不应修改冻结工件。
