# 论文结论的边界

这份仓库复现的是论文中已经冻结的聚合结果，不是新的研究执行环境。

## 证据覆盖的内容

- 在记录的发现样本总体、关系映射、干预和读出方式下，存在 hard-mask 敏感性；
- 记录中的 Gate C 算子迁移联合条件未通过；
- T1 中 hard-minus-mapped-mass 差异在匹配敏感读出之前出现；
- T2 给出冻结区间内的配对分类，同时强阳性对照未通过。

这些结论依赖论文中写明的样本总体、模型检查点、算子、读出方式、估计目标和不确定性程序。

## 不能从这份证据推出的内容

不能据此推出通用的有害查询边、干预不变机制、检测器整体退化、总体发生率、已校准的算子迁移或训练正则化效果。

另一个容易混淆的地方是原生端点：H4-D 的原生指标是分解分析中的派生摘要，T0 的原生指标是统一估计目标审计中的端点。它们不合并、不比较、不替代。

## 复现时实际读取什么

运行脚本只读取 `artifact/analysis_ready/`，并使用其中已有的结果字段完成聚合。它不读取 V/F、图像像素、模型权重或私有凭据，也不进行新的样本选择、训练或推理。
