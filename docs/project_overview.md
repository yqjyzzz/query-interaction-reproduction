# 项目概览

## 科学问题

项目研究集合预测模型中的查询交互：局部查询读出的改善，是否一定意味着固定分配关系下的预测集合也得到改善？冻结结果表明，两者可能出现相反方向，因此论文同时保留局部、固定分配、重新匹配、选择条件和原生读出，避免用单一指标替代不同估计目标。

## 分析链条

- **H4-D**：检查发现样本中的主要删除响应；
- **Gate C**：检查记录中的算子迁移联合条件；
- **T1**：定位 hard-minus-mass 差异是在匹配敏感读出之前还是之后出现；
- **T2**：在确认样本中执行 M/P/D 配对分类，并检查强阳性对照。

四个组件共同限制结论范围。特别是，T2 的阳性对照结果必须与配对分类一起解释，不能把区间内等价直接提升为机制确认。

## 最短复现路径

```powershell
python -m pip install -e ".[test]"
python scripts/check_repository.py
```

这组命令会校验冻结输入、重算四组聚合结果并执行全部仓库测试。过程只需要 CPU，不依赖图像、模型权重或网络。

## 推荐阅读顺序

1. `README.md`：研究问题、双轨结构和运行方式；
2. `docs/experiment_map.md`：四个分析组件之间的关系；
3. `docs/results_guide.md`：结果文件的解释方式；
4. `docs/architecture.md`：代码边界与维护契约；
5. `artifact/reproduced/REPRODUCTION_VALIDATION.json`：归档复现回执；
6. `cv_demo/README.md`：独立视觉检测轨道的接入方法。

## 复现范围

论文轨道复现的是冻结聚合结果，不是原始训练与推理。独立视觉检测轨道可以运行模型，但其结果属于单独的工程运行，不能替换论文数字或进入冻结证据链。
